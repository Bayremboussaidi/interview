

int, double, float, boolean, char... → parameter change ❌ original unchanged
Array, List, Object, HashMap, HashSet... → modifying contents ✅ original can change







// Primitive → NOT changed
void change(int x) {
    x = 100;
}

int a = 10;
change(a);
// a == 10


// List → contents CAN change
void change(List<Integer> list) {
    list.add(100);
}

List<Integer> numbers = new ArrayList<>();
numbers.add(10);

change(numbers);
// numbers = [10, 100]
