1. REVERSE AN ARRAY
------------------------------------------------

Scenario:
You have [1, 2, 3, 4, 5] and want [5, 4, 3, 2, 1].

Code:

int[] arr = {1, 2, 3, 4, 5};

int left = 0;
int right = arr.length - 1;

while (left < right) {

    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;

    left++;
    right--;
}

Use this when:
- You need to reverse an array.
- You want to modify the original array.
- You want O(n) time and O(1) extra space.

IMPORTANT:
left = beginning
right = end

left < right means continue until they meet.

2. VARIABLES + PARAMETERS + RETURN
================================================

A method:

public static int sum(int x, int u) {
    int result = x + u;
    return result;
}

Calling it:

int m = sum(5, 3);

m = 8


PARAMETERS:

public static int sum(int x, int u)
                         ↑      ↑
                      parameters


ARGUMENTS:

sum(5, 3);
    ↑  ↑
 arguments


RETURN:

public static int sum(int x, int u) {
    return x + u;
}

"return" sends the result back to whoever called the method.

Example:

int m = sum(5, 3);

The method calculates:

5 + 3 = 8

Then:

return 8;

So:

m = 8


If the method returns nothing:

public static void printName(String name) {
    System.out.println(name);
}

No return value.

3. WHEN DOES A PARAMETER CHANGE?
================================================

Primitive types:

public static void change(int x) {
    x = 100;
}

int a = 10;

change(a);

System.out.println(a);

Result:

10

The original 'a' does NOT change.

Why?

int is primitive.

The method receives a copy of the value.


IMPORTANT:

Java is always PASS-BY-VALUE.


For objects/arrays, the value passed is the reference.

Example:

public static void change(int[] arr) {
    arr[0] = 100;
}

int[] numbers = {1, 2, 3};

change(numbers);

System.out.println(numbers[0]);

Result:

100

The array changed.


So remember:

Primitive:
int, double, float, boolean, char, etc.

Method gets a copy of the value.

Object/Array:
The method receives a copy of the reference,
so modifying the object/array itself is visible outside.


Example:

int x = 10;

method(x);

x is NOT changed.


Example:

int[] arr = {1, 2, 3};

method(arr);

arr[0] can be changed by the method.


IMPORTANT:
If you reassign the parameter itself, the original reference
does NOT change.

public static void change(int[] arr) {
    arr = new int[]{100, 200};
}

int[] numbers = {1, 2, 3};

change(numbers);

numbers is still:

[1, 2, 3]


But:

public static void change(int[] arr) {
    arr[0] = 100;
}

numbers becomes:

[100, 2, 3]

26. TWO SUM
================================================

Scenario:

[2, 7, 11, 15]

target = 9

2 + 7 = 9


Solution:

HashMap<Integer, Integer> map = new HashMap<>();

for (int i = 0; i < nums.length; i++) {

    int complement = target - nums[i];

    if (map.containsKey(complement)) {

        return new int[] {
            map.get(complement),
            i
        };
    }

    map.put(nums[i], i);
}

return new int[0];


Important pattern:

target - current = what I need

34. BINARY SEARCH
================================================

ONLY use when the array is sorted.


int left = 0;
int right = arr.length - 1;

while (left <= right) {

    int mid = left + (right - left) / 2;

    if (arr[mid] == target) {
        return mid;
    }

    if (arr[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}

return -1;


Complexity:

O(log n)
