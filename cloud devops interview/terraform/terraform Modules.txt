
why modules ? 

- think  that  main.tf  is gross , have  so many ressources , das wird so durcheinander , deswegen bevorzugen 

wir module  architecture  anzuwanden 



-----------------

exemple : 

project/
│
├── main.tf                  ← calls the modules
├── variables.tf             ← root variables
│
└── modules/
    │
    ├── ec2/                 ← EC2 reusable module
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    │
    ├── vpc/                 ← VPC reusable module
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    │
    └── rds/                 ← RDS reusable module
        ├── main.tf
        ├── variables.tf
        └── outputs.tf

module in tera , is something reusable  , like here

resource "aws_instance" "server" {
  ami           = var.ami
  instance_type = var.instance_type
}

In the root main.tf, you call the module:

module "dev_server" { 					// root module 
  source        = "./modules/ec2"  //  Child module
  ami           = "ami-123456"
  instance_type = "t3.micro"
}








terraform import module.vpc.aws_vpc.main vpc-0123456789abcdef0
