exp : 
db_password	TF_VAR_db_password
aws_region	TF_VAR_aws_region






1. Define the variable in variables.tf:
variable "db_password" {
  type      = string
  sensitive = true              // so terr dont show it in the  output now
}


2. Set the environment variable in Windows PowerShell:
$env:TF_VAR_db_password = "MySecret123!"

Where is the state file physically stored?    ( Terraform state file (terraform.tfstate)  )
It depends on your backend.

- Local backend: Usually in your project directory as terraform.tfstate.
- AWS S3 backend: In an S3 bucket at the configured state key.
- Other remote backends: In the storage system configured for that backend.
Terraform can also keep copies of prior local state files, such as terraform.tfstate.backup.
