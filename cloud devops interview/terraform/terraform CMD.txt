terraform init

terraform plan
terraform apply





terraform init
→ first command after creating/cloning the project
→ downloads the AWS provider

terraform fmt
→ after writing/changing .tf code
→ formats your code

terraform validate
→ after writing/changing code
→ checks whether Terraform configuration is valid

terraform plan
→ before creating/changing AWS infrastructure
→ shows you what Terraform WOULD do

terraform apply
→ actually creates/changes AWS infrastructure
