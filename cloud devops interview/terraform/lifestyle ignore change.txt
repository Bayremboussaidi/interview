

Imagine your Terraform code creates an S3 bucket with this tag:


resource "aws_s3_bucket" "example" {
  bucket = "my-example-bucket"

  tags = {
    Environment = "production"
  }
}


2- someone manually  edit the tag

 3 terraform apply -> Terraform detects the difference and proposes changing the tag back to production.





so  if u wanna  ignore that  , add in the ressource block 


lifecycle {
  ignore_changes = [tags]
}
