Create a Dockerfile using Node.js 20.
Copy the application files.
Install dependencies.
The application listens on port 3000.
Start the application with npm start.




FROM node:20-alpine

COPY package*.json ./

RUN npm install

COPY . . 

EXPOSE 3000

CMD ["npm" , "start"]

Create a Dockerfile using Python 3.12.
Copy requirements.txt.
Install dependencies.
Copy the application.
The application listens on port 5000.
Set APP_ENV=production.
Start the application.





FROM python:3.12

WORKDIR /app  ( related to the container dir , always add it  ) 

COPY *.txt .

RUN pip install

COPY . .  ( copy all the files  from .. inside  the container )

EXPOSE 5000

ENV APP_ENV=production     ( ENV ..      ta3 l environnement )

Exercise

Create a MySQL database and a WordPress application.
MySQL should use password db_pass123.
WordPress should connect to MySQL.



docker-compose.yml


services:

  mysql:
    image: mysql:8
    environment:
      MYSQL_ROOT_PASSWORD: db_pass123
      MYSQL_DATABASE: wordpress

  wordpress:
    image: wordpress:latest
    ports:
      - "8080:80"
    environment:
      WORDPRESS_DB_HOST: mysql
      WORDPRESS_DB_PASSWORD: db_pass123
      WORDPRESS_DB_NAME: wordpress
    depends_on:
      - mysql



cmd :  docker compose up -d
