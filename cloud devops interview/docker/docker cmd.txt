# 3. ▶️ CONTAINER STARTEN / STOPPEN

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**docker run IMAGE**

→ Erstellt und startet einen neuen Container.

**docker start CONTAINER**

→ Startet einen vorhandenen Container.

**docker stop CONTAINER**

→ Stoppt einen Container.

**docker restart CONTAINER**

→ Startet einen Container neu.

**docker pause CONTAINER**

→ Pausiert einen Container.

**docker unpause CONTAINER**

→ Setzt einen pausierten Container fort.

**docker kill CONTAINER**

→ Beendet einen Container sofort.

**docker rm -f CONTAINER**

**docker container prune**

→ Löscht alle gestoppten Container.

# 6. 🏃 DOCKER RUN

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**docker run IMAGE**

→ Erstellt und startet einen Container.

**docker run -d IMAGE**

→ Startet den Container im Hintergrund.

**docker run -it IMAGE**

→ Startet den Container mit interaktivem Terminal.

**docker run --name NAME IMAGE**

→ Gibt dem Container einen Namen.

**docker run -d --name NAME IMAGE**

→ Startet einen benannten Container im Hintergrund.

**docker run --rm IMAGE**

→ Löscht den Container automatisch nach dem Beenden.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 7. 💻 EXEC – BEFEHLE IM CONTAINER

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**docker exec CONTAINER COMMAND**

→ Führt einen Befehl im Container aus.

**docker exec nginx ls**

→ Zeigt Dateien im Container.

**docker exec nginx pwd**

→ Zeigt das aktuelle Verzeichnis.

**docker exec nginx ps**

→ Zeigt laufende Prozesse.

**docker exec nginx env**

→ Zeigt Umgebungsvariablen.

**docker exec nginx cat /etc/os-release**

→ Zeigt Informationen über das Betriebssystem.

**docker exec -it CONTAINER bash**

→ Öffnet eine interaktive Bash-Shell.

**docker exec -it CONTAINER sh**

→ Öffnet eine interaktive Shell.

**-i**

→ Ermöglicht interaktive Eingabe.

**-t**

→ Stellt ein Terminal bereit.

**-it**

→ Interaktives Terminal.

# 9. 🌐 PORTS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**docker run -p HOST:CONTAINER IMAGE**

→ Verbindet einen Host-Port mit einem Container-Port.

**docker run -p 5000:3000 myapp**

→ Host-Port `5000` → Container-Port `3000`.

**docker port CONTAINER**

→ Zeigt die Port-Zuordnung.

**38282:8080**

→ `38282` = Host-Port.

→ `8080` = Container-Port.

**Merke:**

→ `HOST_PORT:CONTAINER_PORT`

## Bind Mount

**docker run -v HOST_PATH:CONTAINER_PATH IMAGE**

→ Verbindet einen Host-Ordner mit dem Container.

**docker run -v /opt/datadir:/var/lib/mysql mysql**

→ Host `/opt/datadir` → Container `/var/lib/mysql`.

**Merke:**

→ Container löschen ≠ Daten auf dem Host löschen.
