# AWS Cloud Engineer Interview Cheat Sheet

## 1. Connect to an EC2 Instance

### 🇬🇧 English

**Q:** How do you connect to an EC2 instance?

**A:**
For Linux, I use an SSH private key (.pem).
For Windows, I use an RDP password and key pair.

### 🇩🇪 Deutsch

**F:** Wie verbinden Sie sich mit einer EC2-Instanz?

**A:**
Für Linux verwende ich einen privaten SSH-Schlüssel (.pem).
Für Windows verwende ich RDP mit Passwort und Schlüsselpaar.

---

# 2. Highly Available Multi-Tier Architecture

### 🇬🇧 English

**Q:** Describe a highly available application architecture.

**A:**
The Load Balancer is in a public subnet. It distributes traffic to EC2 instances. The application servers and database are in private subnets for better security.

### 🇩🇪 Deutsch

**F:** Beschreiben Sie eine hochverfügbare Architektur.

**A:**
Der Load Balancer befindet sich im öffentlichen Subnetz und verteilt den Traffic auf EC2-Instanzen. Die Anwendung und die Datenbank befinden sich in privaten Subnetzen.

---

# 3. NAT Gateway

### 🇬🇧 English

**Q:** Why do we use a NAT Gateway?

**A:**
A NAT Gateway allows resources in a private subnet to access the Internet without exposing them to incoming Internet traffic.

### 🇩🇪 Deutsch

**F:** Warum verwendet man ein NAT Gateway?

**A:**
Ein NAT Gateway ermöglicht Ressourcen im privaten Subnetz den Internetzugang, ohne sie direkt aus dem Internet erreichbar zu machen.

---

# 4. Why is it secure?

### 🇬🇧 English

The private EC2 keeps its private IP. The NAT Gateway uses its public IP to communicate with the Internet.

### 🇩🇪 Deutsch

Die private EC2 behält ihre private IP-Adresse. Das NAT Gateway kommuniziert mit seiner öffentlichen IP mit dem Internet.

---

# 5. Communication between Subnets

### 🇬🇧 English

**Q:** Can applications in different subnets communicate?

**A:**
Yes. If they are in the same VPC, AWS creates a local route by default, so they can communicate unless blocked by Security Groups or NACLs.

### 🇩🇪 Deutsch

**F:** Können Anwendungen in verschiedenen Subnetzen kommunizieren?

**A:**
Ja. Befinden sie sich in derselben VPC, gibt es standardmäßig eine lokale Route. Die Kommunikation ist möglich, sofern Security Groups oder NACLs sie nicht blockieren.

---

# 6. Security Group

### 🇬🇧 English

**Q:** What is a Security Group?

**A:**
A Security Group is a stateful firewall attached to a resource such as an EC2 instance. It only supports Allow rules.

### 🇩🇪 Deutsch

**F:** Was ist eine Security Group?

**A:**
Eine Security Group ist eine zustandsbehaftete Firewall für Ressourcen wie EC2. Sie unterstützt nur Allow-Regeln.

---

# 7. Network ACL

### 🇬🇧 English

**Q:** What is a Network ACL?

**A:**
A Network ACL is a stateless firewall at the subnet level. It supports both Allow and Deny rules.

### 🇩🇪 Deutsch

**F:** Was ist eine Network ACL?

**A:**
Eine Network ACL ist eine zustandslose Firewall auf Subnetzebene. Sie unterstützt Allow- und Deny-Regeln.

---

# 8. Security Group vs NACL

### 🇬🇧 English

Security Group:

* Resource level
* Stateful
* Allow only

NACL:

* Subnet level
* Stateless
* Allow and Deny

### 🇩🇪 Deutsch

Security Group:

* Ressourcenebene
* Stateful
* Nur Allow

NACL:

* Subnetzebene
* Stateless
* Allow und Deny

---

# 9. When do you use each?

### 🇬🇧 English

Use a Security Group to protect a specific resource like EC2 or RDS.
Use a NACL to protect the entire subnet.

### 🇩🇪 Deutsch

Eine Security Group schützt eine bestimmte Ressource wie EC2 oder RDS.
Eine NACL schützt das gesamte Subnetz.

---

# 10. Ingress vs Egress

### 🇬🇧 English

Ingress = Incoming traffic.
Egress = Outgoing traffic.

### 🇩🇪 Deutsch

Ingress = Eingehender Datenverkehr.
Egress = Ausgehender Datenverkehr.

# 11. EC2 Pricing Models

### 🇬🇧 English

**On-Demand**

* Pay as you go
* Flexible
* Best for unpredictable workloads

**Reserved**

* 1 or 3-year commitment
* Lower cost
* Best for stable workloads

**Spot**

* Cheapest option
* AWS can terminate it
* Best for batch jobs, testing, CI/CD

### 🇩🇪 Deutsch

**On-Demand**

* Bezahlen nach Nutzung
* Flexibel
* Für unvorhersehbare Workloads

**Reserved**

* 1 oder 3 Jahre Bindung
* Günstiger
* Für stabile Workloads

**Spot**

* Sehr günstig
* Kann von AWS beendet werden
* Für Batch-Jobs, Tests und CI/CD

# 12. CloudWatch

### 🇬🇧 English

CloudWatch answers:
**"What is happening?"**

It monitors CPU, memory, logs, alarms, and application performance.

### 🇩🇪 Deutsch

CloudWatch beantwortet:
**„Was passiert gerade?"**

Es überwacht CPU, Logs, Metriken und Alarme.

---

# 13. CloudTrail

### 🇬🇧 English

CloudTrail answers:
**"Who changed something?"**

It records AWS API calls and account activity. During troubleshooting, it helps identify who made a change, when it happened, and which resource was affected.

### 🇩🇪 Deutsch

CloudTrail beantwortet:
**„Wer hat etwas geändert?"**

CloudTrail protokolliert API-Aufrufe und Aktivitäten im AWS-Konto. Bei Problemen zeigt es, wer welche Änderung wann durchgeführt hat und welche Ressource betroffen war.
